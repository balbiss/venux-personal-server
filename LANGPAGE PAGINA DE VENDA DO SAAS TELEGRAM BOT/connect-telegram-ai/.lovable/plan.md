
# Connect SaaS - Landing Page de Alta Conversão

## Visão Geral
Landing page moderna com estética "Telegram Dark Mode" para o Connect SaaS, uma plataforma de automação de WhatsApp via Telegram.

## Design System
- **Fundo principal:** #0f1721 (azul escuro profundo)
- **Cor de destaque:** #24A1DE (azul Telegram) com efeitos de glow/brilho
- **Texto:** Branco para títulos, cinza claro para corpo
- **Fontes:** Inter/sistema, moderna e limpa
- **Elementos visuais:** Gradientes sutis, bordas com glow azul, ícones Lucide minimalistas

## Estrutura da Página

### 1. Hero Section
- Headline e subheadline conforme especificado
- Botão CTA "Quero Começar Agora" com efeito glow azul pulsante
- Background com gradiente radial sutil azul
- Animação suave de entrada dos elementos

### 2. Seção de Inteligência Artificial (Destaque)
- Título "O Agente de IA mais completo do mercado"
- 3 itens com ícones (RAG, System Prompt, Entendimento Total)
- Layout em cards com borda glow azul e fundo semi-transparente
- Ícones representativos para cada funcionalidade

### 3. Seção de Vendas e Gestão (4 Cards)
- Grid 2x2 (desktop) / coluna (mobile) com os 4 cards:
  - Disparos, Rodízio Inteligente, Transbordo, Follow-up
- Cada card com ícone, título e descrição
- Hover effect com glow azul mais intenso

### 4. Seção Visual - Mockup do Celular
- Ilustração/mockup CSS de um celular mostrando interface do bot Telegram
- Botões simulados: "Configurar RAG", "Ver Rodízio", "Agendar Disparo"
- Efeito de brilho ao redor do mockup

### 5. Rodapé
- "Desenvolvido por InoovaWeb | Balbis"
- Estilo minimalista com separador sutil

## Responsividade
- Totalmente responsivo para mobile, tablet e desktop
- Cards empilham em coluna no mobile
- Mockup do celular redimensiona proporcionalmente
